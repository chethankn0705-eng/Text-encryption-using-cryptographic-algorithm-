# Text-encryption-using-cryptographic-algorithm-

A simple Python project that performs Text Encryption and Decryption using a cryptographic algorithm (AES) with the help of the cryptography library.
This project demonstrates how symmetric encryption works using Fernet (AES-based encryption).

📌 Features
✅ Generate a secure encryption key
✅ Save and load secret key from file
✅ Encrypt user input text
✅ Decrypt encrypted text
✅ Error handling for invalid inputs
✅ Beginner-friendly structure

🛠 Technologies Used
Python 3.x
Cryptography Library (Fernet - AES)
OS module (for file handling)
